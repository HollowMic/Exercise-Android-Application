# Exercise Application

An application for recording your gym sessions

***

<img src="/assets/images/Exercise Application Light.jpg" width="360" height="760" alt="Exercise Application Light">
<img src="/assets/images/Exercise Application Dark.jpg" width="360" height="760" alt="Exercise Application Dark">

### Current features:
- Add and record weight-based workouts
  - Set weight, number of repetitions, and number of sets
  - Add notes to each days workout
- Remove old workouts (non-destructive)
- Export and import the database

### Future features:
- Cardio-based workout adding and recording
- Graphs analysing progress through different workouts
